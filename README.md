# gumball_run
Half-life week 2 project, merbl run
My project for week 2 was originally supposed to be a marble run modeled like a mouse-coaster, but I later decided to change it to a gumball machine-like design. 

I began this project by working on some basic parts and modeled a track and a funnel on onshape.

After this I began working on the main component of my gumball machine design, which was the spiral. For the spiral I used a base drawing and the helix tool. Then, using sweep, I turned the entire thing into a part. 
<img width="4032" height="3024" alt="image" src="https://github.com/user-attachments/assets/4a42ec0c-5b53-4587-8a38-c50f91f771aa" />
For connecting the funnel and spiral parts, I decided on adding another part to keep the marble from falling out.
<img width="4032" height="3024" alt="part" src="https://github.com/user-attachments/assets/eb034bfb-bc23-4b9b-b037-f30755229915" />
Then I figured the tube tracks were not really working with my design so I deleted them and added a base to catch the marble after the spiral.
